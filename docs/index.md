# 自然语言处理

> 西安交通大学 · 2027 年秋 · 32 学时

---

## 课程简介

本课程介绍自然语言处理（Natural Language Processing, NLP）的基本概念、经典方法与前沿进展。课程从文本预处理与语言模型基础出发，经词表示、序列建模，进入注意力机制与 Transformer，进而覆盖预训练语言模型与大语言模型；并结合文本分类、序列标注、机器翻译、检索增强生成等任务开展实验，帮助学生建立"原理—方法—系统"贯通的完整认识。

学完本课程，学生应能够：

1. 理解 NLP 的核心任务、评价指标与基本方法；
2. 使用 Python 与主流深度学习框架完成典型 NLP 任务的建模与实验；
3. 读懂并复现本领域代表性论文的主要思想；
4. 独立完成一个中等规模 NLP 课程项目并撰写技术报告。
